# N11 — API notları (M6-B)

Kaynak: `developer.n11.com/documentation` (2026-09-19'da okundu). Eski SOAP
(`api.n11.com/ws/*.wsdl`) KAPSAM DIŞI; yalnız REST kullanılır.

## Kimlik doğrulama

- Her isteğe `appkey` ve `appsecret` **başlıkları** (HTTP başlık adları
  büyük/küçük harf duyarsız; portal `appKey`/`appSecret` yazıyor).
- Anahtarlar: n11 Mağaza Yönetimi → Hesabım → API Erişimi.
- Sandbox bilinmiyor → **doğrulanmalı**; yoksa gerçek mağazada `size=1` ile
  bağlantı testi yapılır.
- Hız sınırı: **1 dakikada en fazla 1000 istek** (portal notu).

## Sipariş listeleme

`GET https://api.n11.com/rest/delivery/v1/shipmentPackages`

| Parametre | Tür | Not |
|---|---|---|
| `startDate` / `endDate` | long, **epoch ms (GMT+3)** | Tarih aralığı |
| `status` | string | Created, Picking, Shipped, Cancelled, Delivered vb. (tam küme doğrulanmalı) |
| `page` | int | 0 tabanlı |
| `size` | int | **en fazla 100** |
| `orderNumber`, `packageIds` | string | tekil arama |
| `orderByField` | boolean | true: paket güncelleme tarihi |
| `orderByDirection` | ASC/DESC | |
| `sender` | SELLER / n11 / ALL | |

Yanıt: `content[]` + `pageCount/totalPages/page/size` — **Trendyol zarfıyla
aynı biçim**. Paket alanları da Trendyol adlarıyla:

- `id` (paket no = `siparisKimligi`), `orderNumber`, `shipmentPackageStatus`,
  `cargoTrackingNumber`, `cargoProviderName`, `customerfullName`,
  `lastModifiedDate`, `agreedDeliveryDate`
- `shippingAddress { address, city, district, gsm, postalCode }`
- `lines[] { productId, productName, stockCode, barcode, quantity, price, … }`

Notlar:
- Kasım 2024 öncesi siparişler bu servisten gelmez.
- Konuma özel teslimatta paket numarası `null` dönebilir → kimliksiz satır
  atlanır (`siparisNormalle` null döner).
- E-ihracat siparişleri `micro=true`.
- Tarih aralığı sınırı belgede yok → `azamiPencereGun: 14` ile Trendyol gibi
  bölünür (güvenli taraf).

## Ürün sorgulama

`GET https://api.n11.com/ms/product-query`

| Parametre | Not |
|---|---|
| `page` | 0 tabanlı |
| `size` | varsayılan 20, **en fazla 250** |
| `productStatus` | Active, InCatalogApproval, Suspended, CatalogRejected, Prohibited, Unlisted, InApproval |
| `saleStatus` | On_Sale, Out_Of_Stock |
| `sender` | SELLER (varsayılan) / N11 / ALL |

Yanıt alanları: `n11ProductId`, `stockCode`, `title`, `barcode`, `status`,
`saleStatus`, `imageUrls[]`, `categoryId`, `quantity`, `salePrice`.
Sayfalama: `totalPages`; içerik boş dönünce bitti sayılır.
Marka adı yanıtta ayrı alan olarak görünmüyor (`brandName` yalnız filtre) →
`marka: null`.

## Eşleme kararları

- `siparisKimligi = id`, `siparisNo = orderNumber`, `kargoTakipNo =
  cargoTrackingNumber`, `kargoFirmasi = cargoProviderName`.
- Durum tablosu: Trendyol adları birebir (Created/Picking/Shipped/Delivered/
  Cancelled…); tanınmayan → Created + uyarı (`lib/pazaryeri/durum.ts`).
- Kalem barkodu `barcode || stockCode`.
- Sağlayıcı Trendyol istemcisiyle aynı iskeleti paylaşır; fark: taban adres,
  başlıklar (Basic yerine appkey/appsecret), sayfa boyutu 100, ürün ucu.

## Doğrulanacaklar

1. `shipmentPackageStatus` tam kümesi (özellikle iptal/iade adları).
2. `startDate/endDate` için azami aralık var mı.
3. Sandbox var mı; yoksa test gerçek mağazada.
4. Hız sınırı 429 döndürüyor mu, `Retry-After` var mı.
